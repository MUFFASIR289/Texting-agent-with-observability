### Skills to Know About
- `/clear` — wipes conversation context for a fresh start. Used between unrelated tasks so earlier work doesn't bleed into the next one.
- `/context` — shows what's consuming the context window. Worth checking before a long session.
- `/compact` — compresses conversation history when a session runs long instead of losing it to `/clear`.
- `/effort` — adjusts how much reasoning Claude puts into a task.
- `/usage-credits` — checks remaining credits.
- `/ponytail` — the ponytail plugin is installed and active in this repo. It biases Claude toward the smallest solution that works: stdlib over dependencies, one line over fifty, and questioning whether code needs to exist at all.
